Weather Prediction documentation
================================

**Weather Prediction** is an application to analyze weather data collected from an free API, and predict the weather for the next hour based on 
meteorological data. The application is built using Python, PostGreSQL and Streamlit.
.. note::
   This project is under active development.

Check out the :doc:`usage` section for further information, including how to :ref:`installation` the project.
